EXP WEBSITE V2
Upload index.html to a static host.

Recommended launch path:
1. Create a GitHub account.
2. Create a repository named exp-mobile-phlebotomy.
3. Upload index.html.
4. Enable GitHub Pages under Settings > Pages.
5. Publish from the main branch.
6. Connect a custom .com domain later.

The booking form is a prototype that opens an email request. Do not use it to collect sensitive medical information. Before launch, replace it with a secure booking/intake workflow appropriate for the information you plan to collect.
